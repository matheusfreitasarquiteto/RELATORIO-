# RELATORIO-
Formulário HTML para relatórios de estágio da UFV, com cabeçalho institucional personalizável, cadastro de dados do estagiário e do estágio, inclusão de projetos e suas atividades, prévia em tempo real e exportação em PDF A4. Inclui espaços para assinaturas eletrônicas gov.br. Funciona no navegador, sem instalação, e pode ser hospedado na internet.
